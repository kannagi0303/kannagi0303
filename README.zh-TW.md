## 開發的初心

我開始製作軟體的原因很簡單，因為沒有適合自己的軟體。

有些軟體已經能滿足我八成的需求，但剩下的兩成，往往正是我所在意的地方。這並不代表那些軟體不好，只是每個人的需求、習慣與喜好都不相同。

我喜歡簡單的設計，以及使用時幾乎沒有心智負擔的軟體。

簡單並不代表功能少。軟體背後的技術可以很複雜，但使用起來不必如此。

我的專案實際擁有的功能，往往比我公開介紹的還要多。許多功能從未被特別公布，也沒有寫成文件。我希望使用者能透過介面本身，自然而然地發現並使用這些功能。

我不一定追求創造全新的技術。世界上已經有許多優秀的技術，如何將它們適當地組合，讓它們發揮更多價值，也是我享受開發的地方。

我在意執行效率、資源消耗、安裝的便利性，以及日常使用中的各種小細節。

我喜歡用更少的資源，做到更多的事情。

## 關於開發與維護

這些專案都是利用我全職工作以外的時間製作的。

我的時間與資源有限，通常沒有縝密的測試計畫，也沒有足夠的時間驗證所有可能的使用情境、硬體與系統環境。

歡迎提出問題、意見與建議，但我無法保證問題修復的速度、功能實作的時間，以及新版本的發布日期。

## 關於語言

我的母語是繁體中文，也使用日文與英文。

你可能會注意到，我使用的英文相當簡單，有時文法或表達方式也不那麼自然。

我主要使用英文撰寫文件，是希望來自不同國家的人都能閱讀。而閱讀這些文件的人，也不一定以英文為母語。

我更傾向使用常見的單字、簡短的句子，以及容易理解與翻譯的表達方式。

就像我所製作的軟體一樣，我也希望閱讀這些文字時，能盡可能減少心智負擔。

歡迎使用英文、繁體中文或日文與我交流。
