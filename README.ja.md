## ソフトウェアを作る理由

私がソフトウェアを作り始めた理由は単純です。自分に合うソフトウェアが見つからなかったからです。

自分の求めることの8割を満たしてくれるソフトウェアもありますが、残りの2割こそ、私が大切にしている部分であることがよくあります。そのソフトウェアが悪いというわけではありません。必要なものや使い方、好みは人それぞれです。

私はシンプルなデザインと、あまり考えずに使える、負担の少ないソフトウェアが好きです。

シンプルであることは、機能が少ないことではありません。裏側の技術が複雑でも、使い方まで複雑である必要はありません。

私のプロジェクトには、紹介している以上の機能があることがよくあります。その多くは特に告知しておらず、ドキュメントにも書いていません。ユーザーが画面を操作する中で、自然に機能を見つけて使えるようになればと思っています。

私は必ずしも新しい技術を生み出すことを目指しているわけではありません。すでに優れた技術は数多くあります。それらを組み合わせ、より有効に活用する方法を考えることも、開発の楽しみの一つです。

処理効率、リソースの消費、導入のしやすさ、そして日常的に使うときの細かな部分を大切にしています。

少ないリソースで、より多くのことを実現するのが好きです。

## 開発とメンテナンスについて

これらのプロジェクトはすべて、フルタイムの仕事以外の時間を使って開発しています。

使える時間やリソースには限りがあります。綿密なテスト計画を立てることは少なく、あらゆる利用状況、ハードウェア、システム環境を検証する時間も十分にはありません。

不具合の報告、ご意見、ご提案は歓迎します。ただし、不具合を修正するまでの時間、機能の追加時期、新しいバージョンの公開日などはお約束できません。

## 言語について

母語は中国語（繁体字）です。日本語と英語も使います。

私が使う英語はとてもシンプルで、文法や表現があまり自然ではないと感じることもあるかもしれません。

ドキュメントを主に英語で書いているのは、さまざまな国の方に読んでもらいたいからです。読む方すべてが英語を母語としているわけではありません。

私は、よく使われる単語や短い文、理解しやすく翻訳しやすい表現を好みます。

ソフトウェアと同じように、文章を読むときの負担もできるだけ少なくしたいと思っています。

英語、中国語（繁体字）、日本語のいずれでも、お気軽にご連絡ください。
